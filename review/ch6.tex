\section{第6章\quad Bootstrap 与 Jackknife}

\subsection{故事：没有总体，怎么"重复实验"？}

第 3 章评估估计量的套路是"从总体反复抽样"。可现实中我们\textbf{根本不知道总体}，
手里只有一份数据 $x_1,\dots,x_n$。重复实验做不了，难道就没法知道 $\hat\theta$ 的
标准误了吗？

Efron（1979）的天才想法：既然不知道总体 $F$，就用\textbf{经验分布 $F_n$ 冒充总体}
——把手里的 $n$ 个数据点各赋 $1/n$ 概率当成一个"小总体"，
从它\textbf{有放回}地抽样来模拟"重复实验"。
这就像"拔着自己的鞋带把自己提起来"（bootstrap 的字面意思），
听着离谱，但理论证明：$n$ 不太小时 $F_n\approx F$，模拟出的波动确实近似真实波动。

\begin{kbox}{MC（第3章）vs Bootstrap（本章）一句话对比}
\begin{itemize}[leftmargin=2em]
  \item MC 模拟：总体已知 $\to$ 从\textbf{真总体}反复抽新样本；
  \item Bootstrap：总体未知 $\to$ 从\textbf{经验分布 $F_n$}（即原样本本身）有放回重抽。
\end{itemize}
\end{kbox}

\subsection{Bootstrap 估计标准误与偏差}

\begin{ebox}{核心算法（必背）}
\begin{enumerate}[leftmargin=2em]
  \item 从原样本 $\{x_1,\dots,x_n\}$ 中\textbf{有放回}抽 $n$ 个，得 Bootstrap 样本
  $x^{*(1)}$，算 $\hat\theta^{*(1)}$；
  \item 重复 $B$ 次（常取 $B=1000$）得 $\hat\theta^{*(1)},\dots,\hat\theta^{*(B)}$；
  \item 汇总（记 $\bar\theta^*=\frac1B\sum_b\hat\theta^{*(b)}$）：
  \[
  \widehat{se}_B=\sqrt{\frac{1}{B-1}\sum_{b=1}^B\big(\hat\theta^{*(b)}-\bar\theta^*\big)^2},
  \qquad
  \widehat{\mathrm{Bias}}_B=\bar\theta^*-\hat\theta .
  \]
\end{enumerate}
偏差校正估计：$\tilde\theta=\hat\theta-\widehat{\mathrm{Bias}}_B=2\hat\theta-\bar\theta^*$。
\end{ebox}

\paragraph{为什么偏差是 $\bar\theta^*-\hat\theta$？}
真实世界里偏差是 $\E_F\hat\theta-\theta$："样本上的估计"平均偏离"总体真值"多少。
Bootstrap 世界里把 $F_n$ 当总体，其"真值"就是 $\hat\theta$，
"样本上的估计"就是 $\hat\theta^*$，于是偏差被模拟为 $\bar\theta^*-\hat\theta$。
\textbf{记忆口诀：Bootstrap 世界整体往下平移一层}（$F\to F_n$，$\theta\to\hat\theta$，$\hat\theta\to\hat\theta^*$）。

\begin{exbox}[小数据 Bootstrap 手算]
样本为 $\{1,2,6\}$，估计量为样本均值 $\hat\theta=\bar x=3$。
某次 Bootstrap 抽到 $B=4$ 个重抽样本：
$(1,1,6),(2,6,6),(1,2,2),(6,2,1)$。求 $\widehat{se}_B$ 与 $\widehat{\mathrm{Bias}}_B$。
\end{exbox}
\begin{sol}
各重抽样本均值：$\hat\theta^{*}=\frac{8}{3},\ \frac{14}{3},\ \frac{5}{3},\ 3$。
\[
\bar\theta^*=\frac{8/3+14/3+5/3+9/3}{4}=\frac{36/3}{4}=3 .
\]
偏差：$\widehat{\mathrm{Bias}}_B=3-3=0$（均值估计本来就无偏，合理）。

标准误：偏差平方和
$=(\tfrac{8}{3}-3)^2+(\tfrac{14}{3}-3)^2+(\tfrac{5}{3}-3)^2+(3-3)^2
=\tfrac19+\tfrac{25}9+\tfrac{16}9=\tfrac{42}9$，
\[
\widehat{se}_B=\sqrt{\frac{42/9}{4-1}}=\sqrt{\frac{14}{9}}\approx1.25 .
\]
（实际中 $B=4$ 太小，仅为演示计算流程。）
\end{sol}

\begin{exbox}[偏差校正的经典例子]
用 $\hat\sigma^2=\frac1n\sum(x_i-\bar x)^2$（除 $n$ 版本）估计方差。
已知其偏差为 $-\sigma^2/n$。说明 Bootstrap 偏差校正在此的作用。
\end{exbox}
\begin{sol}
$\E\hat\sigma^2=\frac{n-1}{n}\sigma^2$，偏小。
Bootstrap 可在不知道理论公式的情况下"测出"这个负偏差：
$\bar\theta^*-\hat\theta$ 会系统性为负，于是校正值
$2\hat\theta-\bar\theta^*>\hat\theta$，朝真值方向上调——
效果类似把分母 $n$ 改成 $n-1$ 的理论修正，但 Bootstrap \textbf{对任何复杂估计量都通用}。
\end{sol}

\subsection{Jackknife：Bootstrap 的"前辈"}

\paragraph{想法。}不重抽，而是\textbf{每次删掉一个观测}：
$\hat\theta_{(i)}$ 表示删去 $x_i$ 后用剩余 $n-1$ 个数据算的估计，
$\bar\theta_{(\cdot)}=\frac1n\sum_i\hat\theta_{(i)}$。

\begin{kbox}{Jackknife 公式（必背）}
\[
\widehat{\mathrm{Bias}}_J=(n-1)\big(\bar\theta_{(\cdot)}-\hat\theta\big),\qquad
\widehat{se}_J=\sqrt{\frac{n-1}{n}\sum_{i=1}^n\big(\hat\theta_{(i)}-\bar\theta_{(\cdot)}\big)^2}.
\]
系数 $(n-1)$ 的直觉：删一个点引起的变化只有总偏差的 $\sim1/(n-1)$，要放大回去。
只需 $n$ 次计算（Bootstrap 要 $B$ 次），但对中位数等\textbf{不光滑}的统计量失效；
Bootstrap 更通用。
\end{kbox}

\begin{exbox}[Jackknife 手算]
样本 $\{1,2,6\}$，$\hat\theta=\bar x=3$。求 Jackknife 偏差与标准误。
\end{exbox}
\begin{sol}
删一法：$\hat\theta_{(1)}=\frac{2+6}{2}=4$，$\hat\theta_{(2)}=\frac{1+6}{2}=3.5$，
$\hat\theta_{(3)}=\frac{1+2}{2}=1.5$；$\bar\theta_{(\cdot)}=3$。
\[
\widehat{\mathrm{Bias}}_J=(3-1)(3-3)=0\quad(\text{均值无偏}),
\]
\[
\widehat{se}_J=\sqrt{\frac{2}{3}\big[(4-3)^2+(3.5-3)^2+(1.5-3)^2\big]}
=\sqrt{\frac{2}{3}\times3.5}\approx1.53 .
\]
对照：均值标准误的经典公式 $s/\sqrt n=\sqrt{\frac{(1{-}3)^2+(2{-}3)^2+(6{-}3)^2}{2}}/\sqrt3=\sqrt7/\sqrt3\approx1.53$，
完全一致——对均值，Jackknife 恰好还原经典公式。
\end{sol}

\subsection{Bootstrap 置信区间：三种造法}

\begin{kbox}{三种区间（置信水平 $1-\alpha$；记 $\hat\theta^*_{(q)}$ 为 Bootstrap 估计值的 $q$ 分位数）}
\begin{enumerate}[leftmargin=2em]
  \item \textbf{正态近似法}：假定 $\hat\theta$ 近似正态，
  \[
  \hat\theta\pm u_{1-\alpha/2}\,\widehat{se}_B ;
  \]
  \item \textbf{分位数法（percentile）}：直接取 Bootstrap 分布的两端，
  \[
  \big[\hat\theta^*_{(\alpha/2)},\ \hat\theta^*_{(1-\alpha/2)}\big];
  \]
  \item \textbf{枢轴量法（basic/pivotal）}：用 $\hat\theta^*-\hat\theta$ 模拟 $\hat\theta-\theta$ 的分布，
  \[
  \big[2\hat\theta-\hat\theta^*_{(1-\alpha/2)},\ \ 2\hat\theta-\hat\theta^*_{(\alpha/2)}\big].
  \]
\end{enumerate}
\end{kbox}

\begin{wbox}{易错点：枢轴量法的"端点翻转"}
枢轴量法里\textbf{上分位数算下限、下分位数算上限}（被 $2\hat\theta$ 减后大小颠倒）。
考试写反端点是重灾区！检验：算完看下限是否 $<$ 上限。
\end{wbox}

\begin{exbox}[三种区间数值题]
某估计 $\hat\theta=10$，$B=1000$ 次 Bootstrap 得
$\widehat{se}_B=1.5$，$\hat\theta^*_{(0.025)}=7.6$，$\hat\theta^*_{(0.975)}=13.2$。
分别给出三种 95\% 置信区间。
\end{exbox}
\begin{sol}
正态法：$10\pm1.96\times1.5=[7.06,\ 12.94]$。

分位数法：$[7.6,\ 13.2]$。

枢轴量法：$[2\times10-13.2,\ 2\times10-7.6]=[6.8,\ 12.4]$。

注意枢轴量法区间整体向\textbf{左}偏——因为 Bootstrap 分布右偏
（$13.2-10=3.2>10-7.6=2.4$），枢轴量法把这种偏斜"反向"扣回，
分位数法则照单全收。两者差异正反映了分布的不对称。
\end{sol}
